# DUMSAY Shop

Primera implementación estática de la presencia web de DUMSAY Shop.

## Alcance V0.1

Esta versión implementa la estructura funcional definida para la presencia web inicial:

- Inicio
- Cómo funciona
- Comparación
- Sobre DUMSAY
- Contacto
- Marcadores estructurales de Privacidad y Cookies

No contiene catálogo real, precios reales, ofertas, Deal Score cuantificado ni enlaces de afiliación.

## Principio de datos

No se introducen productos, precios, merchants, métricas o resultados comerciales inventados. La incorporación de datos reales queda condicionada al dataset trazable y validable de Gate A.

## Publicación

La implementación está preparada como sitio estático para control de versiones y futura publicación mediante GitHub Pages.
